JavaScript
JavaScript
JavaScript is a high-level programming language used to create interactive and dynamic web pages.
Variables
Variables are named memory locations used to store data values.
Data Types
Data types define the kind of value a variable can hold, such as Number, String, Boolean, Object, etc.
Functions
Functions are reusable blocks of code that perform a specific task when called.
DOM (Document Object Model)
The DOM is a tree-like representation of an HTML document that allows JavaScript to access and modify webpage elements.
Event Handling
Event handling is the process of responding to user actions such as clicks, key presses, and mouse movements.
Async/Await
Async/Await is a feature used to handle asynchronous operations in a simpler and more readable way.
TypeScript
TypeScript
TypeScript is a superset of JavaScript that adds static typing and additional features for better code quality.
Type Annotations
Type annotations explicitly specify the data type of variables, parameters, or return values.
Interface
An interface defines the structure and properties that an object must follow.
Classes
Classes are blueprints for creating objects that contain properties and methods.
Inheritance
Inheritance allows one class to acquire the properties and methods of another class.
Generics
Generics allow writing reusable code that works with different data types while maintaining type safety.
Type Safety
Type safety ensures that values are used according to their declared data types, reducing errors.
React
React
React is a JavaScript library used for building fast and interactive user interfaces.
Component
A component is a reusable piece of UI that represents a part of a webpage.
JSX
JSX (JavaScript XML) is a syntax that allows HTML-like code to be written inside JavaScript.
Props
Props (Properties) are inputs passed from a parent component to a child component.
State
State is a built-in object used to store and manage data within a component.
useState Hook
useState is a React Hook that allows functional components to create and update state variables.
useEffect Hook
useEffect is a React Hook used to perform side effects such as API calls, timers, or DOM updates.
React Router
React Router is a library used for navigation between different pages in a React application.
Single Page Application (SPA)
An SPA is a web application that loads a single HTML page and updates content dynamically without full page reloads.
Express.js
Express.js
Express.js is a lightweight Node.js framework used to build web servers and APIs.
Server
A server is a system that receives requests from clients and sends appropriate responses.
Routing
Routing is the process of defining how an application responds to different URL requests.
Middleware
Middleware is a function that executes between receiving a request and sending a response.
Request
A request is a message sent by a client to a server asking for data or a service.
Response
A response is the data sent by the server back to the client after processing a request.
REST API
A REST API is an interface that allows communication between applications using HTTP methods.
HTTP Methods
HTTP methods are operations used in web communication:
GET – Retrieve data
POST – Create data
PUT – Update data
DELETE – Remove data
MongoDB
MongoDB
MongoDB is a NoSQL database that stores data in flexible JSON-like documents.
NoSQL Database
A NoSQL database stores data in formats other than traditional tables and rows.
Collection
A collection is a group of related documents in MongoDB, similar to a table in SQL.
Document
A document is a single record in MongoDB stored in BSON (Binary JSON) format.
BSON
BSON is the binary representation of JSON used internally by MongoDB.
CRUD Operations
CRUD stands for Create, Read, Update, and Delete operations performed on database records.
Query
A query is a request made to retrieve specific data from a database.
Mongoose
Mongoose is an Object Data Modeling (ODM) library that simplifies MongoDB operations in Node.js applications.
Full Stack Concepts
Frontend
The frontend is the user-facing part of an application that users interact with directly.
Backend
The backend is the server-side part of an application that handles business logic and data processing.
Database
A database is an organized collection of data used for storing and retrieving information.
API
An API (Application Programming Interface) is a set of rules that allows different software systems to communicate.
Client-Server Architecture
Client-server architecture is a model where the client requests services and the server provides them.
JSON
JSON (JavaScript Object Notation) is a lightweight format used to exchange data between applications.
Full Stack Development
Full stack development refers to developing both the frontend and backend of a web application, along with database integration.
These definitions are short and suitable for interview, viva, presentation, or course explanation purposes.
